# 开发过程中遇到的问题

本项目用于记录机器人开发、ROS2、Linux、Python、C++、硬件调试过程中遇到的问题。

## 目的

- 保存错误原因
- 记录解决方法
- 避免重复踩坑
- 形成可检索的机器人开发知识库

## 记录范围

- ROS2 编译失败、节点异常、launch 启动问题
- colcon、CMake、package.xml、依赖配置问题
- Linux、Ubuntu、SSH、网络、权限、驱动问题
- Python、C++ 开发和运行时错误
- CAN 通信异常、达妙电机通信问题、传感器和控制板调试问题

## 记录格式

每个问题建议按以下结构记录：

```markdown
## YYYY-MM-DD 问题名称

### 现象

问题表现、报错信息、复现方式。

### 环境

系统版本、设备、软件版本、连接方式。

### 排查

实际检查过的步骤和结果。

### 原因

最终确认的根本原因。

### 解决

最终有效的解决方案。

### 经验

下次避免重复踩坑的经验总结。
```

以后遇到问题时，可以直接让 Codex：

```text
把这个错误记录到 issues.md
```
