# Linux问题

## 2026-08-03 SSH连接失败

### 现象

ssh连接Ubuntu失败：

```text
Connection refused
```

### 环境

Windows -> Ubuntu 22.04

### 排查

- SSH服务正常
- 22端口正常监听
- ping正常
- TCP 22失败

### 原因

Windows和Ubuntu使用相同固定IP：

```text
192.168.1.199
```

导致局域网IP冲突，SSH连接失败。

### 解决

修改Windows IP，重新连接WiFi，恢复SSH。

### 经验

固定IP不要与其他设备冲突。机器人开发环境中，如果有Ubuntu主机、Windows电脑、Jetson、工控机、电机控制器等设备，需要统一规划IP地址。
